# 快捷键

**1. 基础与文件操作**

- `Ctrl + Shift + P` / `F1`：打开命令面板（VS Code 的灵魂，忘记快捷键时搜这里）
- `Ctrl + P`：快速打开文件（输入文件名即可跳转）
- `Ctrl + S` / `Ctrl + Shift + S`：保存当前文件 / 另存为
- `Ctrl + W` / `Ctrl + K, Ctrl + W`：关闭当前标签页 / 关闭所有标签页
- `Ctrl + \`：拆分编辑器（左右分屏）

**2. 编辑与多光标（效率分水岭）**

- `Alt + ↑/↓`：向上/下移动当前行
- `Shift + Alt + ↑/↓`：向上/下复制当前行
- `Ctrl + D`：选中下一个相同的单词（多光标编辑神器）
- `Ctrl + Shift + L`：一次性选中文档中所有相同的单词
- `Alt + 鼠标点击`：在任意位置添加垂直多光标，批量修改
- `Ctrl + /` 和 `Shift + Alt + A`：切换行注释 / 切换块注释
- `Shift + Alt + F`：一键格式化代码

**3. 查找与导航**

- `Ctrl + F` / `Ctrl + H`：当前文件内查找 / 替换
- `Ctrl + Shift + F` / `Ctrl + Shift + H`：全局搜索 / 全局替换
- `F12` / `Alt + F12`：跳转到代码定义 / 在新标签页查看定义
- `Ctrl + G`：跳转到指定行号
- `Ctrl +` ：打开/关闭集成终端
- Ctrl + Shift + Space 手动打开方法提示

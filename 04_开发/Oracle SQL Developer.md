

| 快捷键          | 作用                      | 用途                                 |
| ------------ | ----------------------- | ---------------------------------- |
| Alt+F10      | 打开新标签页，共享同一个数据库 session |                                    |
| Ctrl+Shift+N | 打开新标签页，单独 session，      | 每个标签页是独立数据库连接，事务互不干扰，用来做锁、并发测试非常好用 |
| Ctrl+Tab     | 切换打开的标签页                |                                    |
| Ctrl+Enter   | 运行单条SQL                 |                                    |
| F5           | 运行SQL脚本                 |                                    |
| Ctrl+F7      | SQL 格式化美化               |                                    |
